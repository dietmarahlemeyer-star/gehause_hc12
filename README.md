# Gehaeuse HC12

Parametrisches OpenSCAD-Projekt fuer ein Elektronikgehaeuse mit Unterteil,
aufgestecktem Deckel, Schraubdomen und seitlichen Aussparungen.

## Struktur

- `scad/` - OpenSCAD-Quelldateien
- `stl/` - exportierte STL-Modelle
- `export/` - Slicer-/Druckexporte wie 3MF und G-Code
- `screenshots/` - Vorschaubilder

Hauptmodell: `scad/gehause.scad`
